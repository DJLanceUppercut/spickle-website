# Spickle Website (Astro build on `master`; `astro-rebuild` kept in sync)

Astro static site for Spickle Cleaning & Sealing (spickle.com.au). Deployed on Vercel project `spickle-website`.
The June React build was replaced on `master` on 15 Nov 2026 (still in history at 75b95e1). `master` deploys to Vercel production (spickle-website.vercel.app); spickle.com.au is not on Vercel until cutover.

## Stack
- Astro, static output (`npm run build` -> `dist/`). No CSS frameworks. Component-scoped `<style>` plus `src/styles/global.css`.
- Fonts: Archivo Variable for body/UI (stand-in until a Brother 1816 web licence is bought) and Marcellus for display headings. Both self-hosted via @fontsource.
- Design direction: Dusk layout with the "light pass" colour balance (approved 15 Nov). White is the default surface, mint (`.band.panel` / `.band.light`) for alternate bands, navy (`.band.dark`, `.band.textured`, the homepage hero, footer, mobile menu) for a few feature moments only, teal for buttons and accents. Roughly 60% light, 30% navy, 10% teal, following the 2022 brand guidelines. Use the surface tokens in global.css (`--strong`, `--text`, `--muted`, `--lede`, `--accent`, `--hairline`, `--card`) rather than hard-coded colours, so text works on both light and dark sections. Stone pages generate from `src/data/stones.js` via `src/pages/[stone].astro`.

## Rules
- Bookings go through ServiceM8's hosted form: `BOOKING_URL` in `src/config/site.js` (it can't be embedded). Every button-style "Book a quote" links straight to it; `/book-now` keeps the calculator and the `BookingCard` component. Do not build a custom booking form.
- Keep the old Strikingly page addresses (/bluestone, /limestone, /granite, /travertine, /slate, /aggregate, /services, /faq, /book-now, /contact) so rankings carry over.
- Anything still needed from Lukey is shown in a `.todo` dashed block. Don't invent facts (years in business, insurance, review counts).
- Pre-launch noindex is controlled by `PRELAUNCH` in `src/config/site.js`. Set it to `false` at cutover. `/404` and `/thank-you` pass `noindex` to Base so they stay out of Google after launch.
- Pages build as `name.html` (`build.format: 'file'`) and Vercel serves them at clean addresses via `cleanUrls` in vercel.json. Don't remove `cleanUrls`: every page except the homepage 404s without it.
- `/sitemap.xml` is generated by `src/pages/sitemap.xml.js` (pages + stones + suburbs + guides). Service-area suburbs live in `src/data/serviceAreas.js`. SEO local pages (`/service-areas/<suburb>`) are built from `src/data/localAreas.js`; flyer campaign pages (`/<suburb>`) from `src/data/suburbs.js`. Every local page needs its own written angle, no copied sentences and no invented facts.
- No em dashes in copy.
- Motion: scroll reveals are CSS scroll-driven animations (`data-reveal` + `animation-timeline: view()` in global.css, inside `@supports` and `prefers-reduced-motion: no-preference`). Don't reintroduce JavaScript reveals that start content at opacity 0.
- Mobile menu is a native `<dialog>` opened with `showModal()` (inert page, Escape and focus handled by the browser). Nav links carry `aria-current="page"`.
- Fonts: when an element switches `font-family`, also set `font-size-adjust: var(--display-adjust)` (Marcellus, 0.5) or `var(--font-adjust)` (Archivo, 0.526) so fallback fonts don't shift layout while web fonts load.
- Range sliders (seal demo, before/after) set `aria-valuetext` so screen readers hear a meaningful value.
